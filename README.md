# TravelPulse

Динамична веб-апликација за планирање патувања и итинерари.

## Структура на проектот
- `part1-static/` - Статички HTML/Bootstrap 5 маски (Дел 1)
- `server.js` - Express.js бекенд сервер (Дел 2)
- `Dockerfile` & `docker-compose.yml` - Docker контејнеризација
